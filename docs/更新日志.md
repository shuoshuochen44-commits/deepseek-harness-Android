# 更新日志

## v0.2.4 — 2026-11-21

- **取消原生黑色顶栏 + 沉浸式状态栏主题同步**：移除顶部 52dp 深色横栏，全屏承载界面并自动保留安全边距；通过安全 `WebMessagePort` 通道实时同步网页明暗主题，浅色模式自动切换白底与深色状态栏/导航栏图标。
- **全面修复弹层与工作目录返回逻辑**：返回键（同时拦截 `onBackPressed` 与 `onKeyDown`）现按最顶层优先栈逐级退出：输入法 → 弹出菜单/下拉列表 → 最顶层模态弹窗（选择工作区目录、新建文件夹、路径编辑态、设置上方二级弹窗等）→ 设置页 → 右侧面板 → 全局功能面板 → 左侧栏 → 会话 → 首页。
- **UI 美化与流畅度升级**：
  - 鲸鱼娘主视觉与空状态插画柔和蓝光氛围投影与 GPU 轻盈悬浮微动效；冰蓝描边「预览版」胶囊、输入框微投影与聚焦高亮、按钮触控微缩反馈。
  - 左侧覆盖式抽屉升级 20px 圆角、分层投影、GPU 滑入动画与毛玻璃遮罩，新增 60fps 跟手左滑收起与左边缘右滑呼出手势（存在弹窗/菜单时自动屏蔽误触）。
  - 设置页横向标签圆角胶囊化、右侧渐隐提示与点击自动居中；优化「选择工作区目录」弹窗移动端排版（44px 目录触控行高与对齐底部操作栏）。
  - 启动页升级深海蓝渐变背景、硬件层悬浮呼吸动效、圆角状态胶囊、渐变水波纹重试按钮与 220ms 交叉淡入转场；优化 WebView 渲染优先级及 `NodeRuntime` 条件唤醒减少启动等待。
  - `MutationObserver` 流式输出叶子节点 O(1) 剪枝，大幅降低对话生成时的 DOM 扫描开销。
- **新增电脑 `ApkStart` 专用 `x86_64` 变体包**：内置 Termux `x86_64` Node 24 LTS 运行时与旧版 WebView 现代 API Polyfill，可在 Windows `ApkStart`（Android 14）上原生运行。
- 40 项前端与导航自动化测试通过（新增工作目录弹窗、叠加弹窗与弹出菜单返回栈回归用例）。
