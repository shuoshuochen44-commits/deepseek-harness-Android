# DSH Android 真机验证

日期：2026-10-27。设备：V2458A，Android 16，屏幕 1260×2800。
最终版本：0.2.3-mobile，versionCode 3，包名 io.dsh.android。

## 本轮发现并修复

1. 展开左侧栏时，桌面网格布局会把 360px 手机页面的中心挤到约 80px。手机现改为覆盖式侧栏，中心内容保持正常宽度，点击遮罩可收起。
2. 右侧全屏面板未计入返回状态，按返回仍停在面板。现使用官方面板状态标记和收起按钮，优先收起右栏。
3. 插件等全局面板的按钮只负责选中页面，重复点击不能退出。现通过官方新会话入口回到首页；历史会话仍可从列表进入。

三处问题均补充回归检查，先确认旧实现失败，再验证修复通过。最终共 38 项自动检查通过，新增改动经独立代码复核。
