# 构建与测试

## 代码补丁

将 app/、tools/ 和 tests/ 中对应文件覆盖到相同版本的原 DSH Android 工程。完整原工程需另备其 Java 外壳其余源码、资源、依赖 JAR、Android 本地运行时与 app/assets/payload.zip。本仓库不包含账号数据或发布签名私钥。

## 构建

需要 JDK、Android SDK build-tools 37.0.0 / platform 36，以及原工程依赖。
设置 JAVA_HOME、ANDROID_SDK_ROOT、DSH_KEYSTORE_PASSWORD；通过 -Keystore 和 -KeyAlias 指定自己的签名文件与别名，然后运行：

    ./tools/build-apk.ps1 -Keystore <签名文件路径> -KeyAlias <签名别名>

公开脚本从环境变量读取签名密码，不内置发布凭据。修改签名后产生的安装包无法覆盖由其他证书签名的安装版本。

## 自动检查

安装 Node.js 20+、JDK 和 Microsoft Edge；运行 npm install。原工程 runtime-asar 中需存在对应官方前端模块。若运行时位于其他目录，设置 DSH_RUNTIME_DIR 为该 runtime-asar 路径。

    npm test

PLAYWRIGHT_MODULE 可指定已有 Playwright 模块的路径，BROWSER_CHANNEL 可指定浏览器通道。共 38 项检查覆盖导航、加载回调顺序、插画、明暗主题、窄屏布局、侧栏和观察器生命周期。
