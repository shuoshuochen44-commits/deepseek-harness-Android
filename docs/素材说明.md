# 插画素材说明

使用内置 image_gen 工具生成两张透明背景插画，再压缩为应用内本地 WebP；未使用 CLI/API 回退模式。
以下是最终提示词的整理版，便于后续保持角色一致。

## 欢迎图提示词
应用首页与启动页插画。蓝色鲸鱼娘，拟人化、可爱卡通风格，蓝色短发，鲸鱼特征与尾巴，蓝白女仆装，亲切挥手，坐在柔和气泡上。整体清爽，呼应 DeepSeek 蓝色品牌。透明背景，无文字、无水印，完整角色与足够留白，适合浅色和深色界面。

## 空白状态提示词
使用欢迎图作为角色和画风参考，保持相同的蓝色头发、鲸鱼特征、蓝白女仆服及可爱卡通比例。角色抱着打开的蓝色文件夹，表现等待添加内容的空白状态。透明背景，少量柔和蓝色装饰，无文字、无水印，适合小尺寸显示和明暗主题。

## 文件
- 原始透明 PNG：本地交付保留原始透明 PNG；仓库中包含压缩后的 WebP。
- 打包文件：app/assets/mobile/welcome.webp（629×440，53,262 字节），empty.webp（480×320，32,738 字节）。
- 原生图标使用原工程中官方鲸鱼矢量轮廓，页面角色插画属于本次定制素材。
